# RAG Knowledge Base Answers

## Project Overview

This repository contains my solution submission for the "RAG Knowledge Base Answers" task.

The objective was to build a Retrieval-Augmented Generation (RAG) pipeline that retrieves relevant information from the provided knowledge corpus and generates answers for user questions.

## Dataset

The task provided the following files:

* questions.csv – user questions
* websites.csv – knowledge base corpus
* sample_submission.csv – submission format

## Approach

* Loaded the provided datasets in Google Colab.
* Processed the knowledge corpus and user queries.
* Retrieved relevant information from the corpus for each question.
* Generated answers based on the retrieved context.
* Exported the final results in CSV format for submission.

## Repository Contents

* submission.csv – final generated answers submitted for evaluation.
